# Magnetic Torque Simulation

This Jupyter Notebook simulates the bending of a magnetized cylinder under a magnetic field.

## How to Run
You can run the notebook directly in your browser:

### Using Binder
[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/LeonAbelmann/cilia/main?filepath=MagneticTorque.ipynb)

### Using Google Colab
[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/LeonAbelmann/cilia/blob/main/MagneticTorque.ipynb)

## Requirements
- Python 3.x
- Libraries: `numpy`, `scipy`, `matplotlib` (automatically installed in Binder/Colab)
